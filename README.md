# 🛰️ Bromichat CLI - Jandosoft

> **Social Terminal Environment** | *Connecting the Unconnected*

Este es el cliente oficial de terminal para la red Bromichat. Diseñado para usuarios avanzados que prefieren la velocidad y potencia de la consola.

## 🚀 Instalación Automática (One-Command)

Si acabas de clonar el repositorio, simplemente ejecuta:

```bash
npm run setup
```

Esto instalará todas las dependencias y registrará el comando `bromichat` globalmente en tu sistema.

## 🛠️ Uso Manual

Si prefieres no instalarlo globalmente:

1. Instala las dependencias: `npm install`
2. Arranca la app: `node index.js` o `npm start`

### Comandos una vez instalada:
Simplemente escribe en cualquier terminal:
```bash
bromichat
```

## 💎 Características Premium
- **Real-Time Engine:** Chat instantáneo vía WebSockets.
- **Global Feed:** Explora y publica en el muro desde la terminal.
- **Jandosoft Encryption:** Conexiones seguras y encriptadas.
- **Multimedia Support:** Visualización de enlaces de imágenes y videos.
